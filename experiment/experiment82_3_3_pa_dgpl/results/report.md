# Experiment 82.3.3 · PA-DGPL

**Patient-Adaptive Decision-Gain Prompt Learning（患者自适应决策收益 Prompt 学习）**

状态 **COMPLETE_AUDITED**，科研判定 **NO-GO**。

研究问题是医学 Prompt 引导的固定谱证据能否经患者级正负残差提高 DARG 的硬分类正确性。E82.3.2 Medical 的门控由全折共享符号决定，实际残差约 0.064%，关闭残差零翻转，方向 KL 的辅助梯度长期偏大。

## 论文与源码审查

原论文的 GFR 为各模态建立患者关系图，并对共享患者特征做 GCN 消息传播。CAM 在同一患者内进行跨模态交互。PEN 通过冻结 CLIP 编码疾病文本，SPGS 用语义相似度重加权局部 token，RES 将局部线索融合到全局特征。论文端到端目标为图损失与分类交叉熵之和。原作者分类头由 LayerNorm、Linear、GELU、Dropout 和二分类 Linear 构成。 [论文](https://papers.miccai.org/miccai-2025/paper/5129_paper.pdf) · [原作者源码](https://github.com/wanxixi11/SPromptGL/tree/ba3b9446fa451fde6864d6555bdf324de0c4b64a)

历史 E61/E69.3/E74.4 的实际路径为 PLNNoPEN 和原 CAM144、OutputLayer。E74.4-G2 继承 E61 epoch 10 的 CAM、优化器和 RNG，按已审计实现恢复关系校准和门控，使用 4096 个有效训练关系对与 Positive-DCR。E82.2 固定 8 个全局协方差方向和 8 个补空间 ASD−TD 对比方向。E82.3 估计合法训练类别的 Gaussian LLR。E82.3.1 引入 EMA 和分方向 LLR 加权。E82.3.2 上传提交的模型、runner、auditor、配置和报告与服务器文件逐字节匹配。 [E82.3.2 固定提交](https://github.com/tangaii/SPromptGL/tree/fdafee986b9dc5609cfb5e8e5e1f59bb156c2b6c/experiment/experiment82_3_2_da_srpe)

## 冻结方法与运行

两组逐折从独立恢复的同一 E74.4-G2 状态开始，逐元素继承 6081 个新分支历史初始化参数、固定医学 Query、八条提示、谱基和 EMA 状态。新增 162→16→1 signed gate 与 4→8→1 beta 网络使用隔离种子 823300+fold、823400+fold，两个末层严格为零。beta 使用旧 beta 的 logit 加上幅值至多 1 的学习修正。实际残差为 signed gate 乘历史平滑限幅谱重建。数值实现对低于 EPS 的 CAM 范数应用比例缩放，以维持字面 8% 上限。

G1 保留完整历史损失 cls + graph + 0.05 pair + 0.01 adv + 0.01 preserve，增加 0.001 倍合法训练残差惩罚。G2 额外使用同一次分类前向图的真类 log 概率差的一阶 CAM 梯度，与实际残差作内积，使用困难度权重和两类等权 softplus。辅助梯度仅传入四组新增参数，系数同时受 0.001 上限和四组最小梯度比的 0.5 倍约束。分类路径端到端训练 DARG、CAM、OutputLayer 与全部新增参数，第四优化器为历史新增分支 AdamW 配置。

所有折使用 seed 0、历史 CV 前 RFE 和 scaling、转导患者图和 val=test。ACC 严格提高才替换 Best，平局保留最早 epoch。训练从 epoch 11 开始，最多至 450，wait>200 早停。Best 核验评估前 EMA，Latest 每 10 轮和终止时保存评估后更新一次的 EMA。Fold2 第 377、407 行的 DARG 历史训练参与照旧，新增类统计、收益监督与标签诊断排除两行，新增残差逐元素为零。

运行目录 `/model/spromptgl/experiment/experiment82_3_3_pa_dgpl`。首选 OSSFS 路径返回 errno 5。GPU0 单卡，最多 10 个折进程，每进程一个数值线程。正式任务 20/20，训练耗时 1666.1 秒，GPU0 采样峰值 14243 MiB，训练失败事件 0。会话中断 1 次，提交的 Latest 精确恢复 5 个任务。

系统自带旧数值依赖时，历史 runner 在 Fold1 的 RNG 校验可重现失败，部分 checkpoint 需要 NumPy 的新版序列化模块。按历史记录恢复 NumPy 2.5.3、SciPy 1.18.1、scikit-learn 1.9.1 和 pandas 3.0.6 后重新完成十折 Preflight。固定阈值与历史 RNG 校验在正式启动前均通过。
