# Experiment 48.4 — Verified APCR-GFR

This experiment has two separately reported parts. First, it reloads all ten Experiment 48.3 E6 best checkpoints with the frozen 48.3 source and performs no-retraining APCR message and neighbor interventions. Second, after SRD pair sampling, same-patient-pair SCA, CRA finite-candidate maximization, controls, and B0-B parity checks pass, it runs the preregistered E0-E10 comparison.

The project path is `/model/spromptgl/experiment/experiment48_4_verified_apcr`. Historical source snapshots, fold anchors and weights are retained under `.runtime`; they are not source-edited. The actual ABIDE source remains read-only under `/data/adodas/SPromptGL-main/data/ABIDE`.

The base GFR+CAM path retains the original PHENO overwrite and excludes PEN and ALoss from the training objective. The APCR path is an additive residual. Historical global preprocessing/CV-before-RFE, 871-node transduction, `val=test` checkpoint selection and single-seed evaluation are retained for protocol comparability and limit unbiased generalization claims.

## Audited call path and research boundary

- `main.py:143-164` creates the fixed 10-fold split and selects checkpoints on `val_idx=test_idx`, updating only when accuracy is strictly higher and stopping after `wait > early`.
- `model.py:122-151` is the active `simple-2` path: `dataLayer -> GFR -> CAM -> ClsLoss + mean(GraphConstructLoss)`. It computes and prints `ALoss`, but does not include it in `loss`.
- `network.py:197-274` constructs four modality-specific GraphLearn adjacency modules and four GCNs. Each GCN is dimensioned for `sum(input_dim)=320` and receives `torch.cat(x, dim=1)`. At `i==1`, `combined_feat` is reassigned, so the PHENO output from `i==0` is overwritten before the final sum.
- The isolated B0-B implementation is in `.runtime/sources/`; it preserves these base semantics and removes PEN. E1 is the zero-residual path; all other APCR paths add a residual to the original GFR output before the unchanged CAM.
- The original GFR graph construction and ALoss are not replaced by the APCR candidate relation graph. APCR candidates are restricted to the threshold-free scores captured from the original GraphLearn forward and add no direct-label graph edges.

The paper review distinguishes prior methods from this experiment's hypotheses. SPromptGL Eq. (1)-(2) uses label-derived graph supervision in the paper and propagates concatenated multimodal features on modality-specific relations; this historical code's `simple-2` does not optimize its computed ALoss. DeepASD aligns modality embeddings to an fMRI anchor before building patient-similarity graphs, which differs from APCR's pair-relation evidence and candidate-edge perturbation. Reliable Conflictive Multi-View Learning and Trust4Conflict motivate view-specific evidence/reliability, UMCGL balances consistency with view diversity, and AAAI 2026 demonstrates that enforced alignment can help or hurt according to shared redundancy. ICML 2025 graph adversarial work studies robust GNN generalization; it does not establish that APCR's finite candidate search improves ABIDE diagnosis. No component here is claimed as a first use of reliability, consistency, or graph adversarial learning.
