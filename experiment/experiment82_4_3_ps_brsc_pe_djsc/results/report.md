## 独立审计及解释边界

独立审计的首次抽查发现，PyTorch AdamW 在重新加载同一 Python checkpoint 对象时共享了 CPU 步数张量。在线见证与第一次独立 Latest 续训重放精确一致。审计修复在加载前复制新增优化器状态，使审计可再次使用原对象。G2 EMA 中长整型样本计数相除得到 float32 的样本方差校正因子，其余矩更新使用 float64。独立审计显式重建该舍入路径，并验证它与理想 float64 公式的差值在单次舍入的理论误差界内。对相近 Gaussian 对数密度与相近分类 Margin 的相减，分别核对上游值与下游变换的误差传递。修复后的独立审计入口重审了全部折。入口支持 `--fold N`，一次重放该折的两个正式组。冻结训练源码、正式配置、磁盘 checkpoint 和日志 SHA 均保留。[独立审计入口](../runtime/audit_restore_repair.py)

GPU 上下文吞吐恢复涉及 G1 Fold 6@150、Fold 7@150、Fold 8@150、Fold 9@150、Fold 10@152，G2 Fold 6@60、Fold 7@60、Fold 8@60、Fold 9@60、Fold 10@60。这些未结束折使用校验的 Latest 续训。训练日志的已提交前缀、状态、EMA 和前后 RNG 衔接均独立验证。已完成折保留原结果。

逐样本概率、类别和 logits 在 Best 与 Latest 的记录评估状态精确一致。Latest 从完整状态继续一步训练、评估和 EMA 与在线见证精确一致。独立回放 7722 个训练 epoch 的六次历史 Dropout 和四类 RNG，归档交集 7318 epoch 的训练前、训练后、评估后共 21954 个阶段全部一致。超出归档终点的 epoch 用同一原生随机操作序列回放。

20/20 通过原始路径关闭后精确行为、新参数初始化 RNG 隔离、Native CE 与残差的端到端梯度、逐族辅助梯度预算、权重冻结和 Fold 2 屏蔽。公式对照按浮点运算界验证，预测和状态身份按确切一致验证。历史 DARG、E82.2-G2、E82.3.2-G2 Best 逐折只读重放。E82.4.2-G2 复核存档输出和六项指标。348 份保护文件在训练前后 SHA 一致。

本结果继承单 seed、val=test 参与选模、CV 之前 RFE/标准化、转导患者图和 Fold 2 重叠。Fold 2 的 377 ASD、407 TD 是历史 1-based 行号，两行保留 DARG 成员身份并从新增拟合和监督排除，新增残差为零。不同实验的配对差受各自 Best epoch 影响。固定权重医学与匿名 Query 比较限于历史模型和数据协议，不能推出独立临床诊断价值或无偏外部泛化。
