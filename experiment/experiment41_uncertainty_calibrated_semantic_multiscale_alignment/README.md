# Experiment 41: UCSMA-v2

**Uncertainty-Calibrated Semantic Multiscale Alignment** tests whether train-only TD normative references, coverage-adjusted ROI and anatomical-family evidence, and rejectable alignment to conservatively mapped literature concepts provide incremental classification value beyond an independently retrained Experiment32 B0-A anchor.

All work is staged under `/tmp/SPromptGL-E41-UCSMA-stage/experiment/experiment41_uncertainty_calibrated_semantic_multiscale_alignment`. The root repository is read-only for this experiment except for an idempotent append to `handoff.md` after final validation. Input features remain the existing ABIDE 871-by-320 processed table and existing modal mapping. The original four-patient-graph GFR, including the `i==1` combined-feature overwrite, original CAM and OutputLayer are preserved. PEN is bypassed only in the private runtime source, while its PLN/CLIP construction side effects remain for E0 anchor parity.

The 252 verified FC endpoints map to 110 of 111 HO ROIs. The four endpoint-unknown FC inputs remain in the original trunk and raw-capacity control but are excluded from anatomical evidence. No canonical functional network mapping is claimed. Candidate anatomical families are explicit atlas-name proxies only.

The normative reference is fitted on outer-train TD participants only. Outer-training participant deviations are generated by five-fold inner cross-fitting; outer-test deviations use the full outer-train TD fit. The conditional design uses age-bin category, sex, site and mean FD; age bins are never treated as continuous ages. Robust residual scales, empirical training-TD thresholds, condition support and acquisition-quality proxies are fitted using training data only. Signed deviations are retained. ROI evidence reports positive and negative deviation separately, tail coverage, reliability and degree shrinkage. These are relative deviations from the processed cohort distribution, not clinical abnormality labels.

UCSMA uses fixed concept-to-ROI/edge masks, empirical reference support and a fixed rejectable evidence mass. It does not use a free text-to-query projection, an LLM call at training time, a new disease head, an MoE, or a second patient graph. The only trainable increment is a shared 64-wide residual adapter, zero-initialized at its output and smoothly bounded to 5% of the CAM norm. E1-E9 use the same adapter parameterization; only the pre-registered evidence fields and ontology/reject switches change. E6 disables rejection, E7 changes only the ROI correspondence, E8 replaces literature masks with outer-train numeric FC clusters while retaining rejection, and E9 uses the literature masks with rejection. The frozen original OutputLayer produces all predictions.

## Frozen protocol

- Seed 0; original `StratifiedKFold(10, shuffle=True, random_state=10)`; continuous RNG stream for E0.
- E0 is an independent 10-fold B0-A retraining and must match Experiment32 fold metrics, best epochs, initialization and fold-entry RNG.
- E1-E9 share the E0 per-fold checkpoint and frozen B0-A CAM/OutputLayer. Branch initialization uses the same deterministic fold-derived seed for every arm.
- Original `val_idx=test_idx`, strict ACC checkpoint updates, 450-epoch cap, patience 200, original weighted classification loss, and for E0 the original double-Adam `simple-2` objective remain unchanged.
- Formal metrics only: ACC, original hard-label one-hot ROC-AUC, SPE-TD and SEN-ASD.
- GPU0: E0, E2, E4, E6, E8. GPU1: E1, E3, E5, E7, E9. No more than four workers per card.
- Historical RFE/standardization precedes outer CV and GFR is transductive across all 871 participants. These inherited choices limit generalization claims.

Run `python run.py prepare`, `CUDA_VISIBLE_DEVICES=0 python run.py preflight`, `python run.py train`, and `CUDA_VISIBLE_DEVICES=1 python run.py report`. `dispatch` and `resume` are aliases for `train`; completed valid folds are skipped. The private source mirror, data-derived caches, logs and resumable checkpoints stay under `.runtime/`.

After report verification, `python run.py finalize` copies this experiment (including its compact recovery state) to the specified project experiment directory, verifies file digests, and appends one idempotent completion section to the existing root `handoff.md`. It never commits or pushes Git. `manifest.json` distinguishes computation completion, delivery synchronization and handoff status; any failed root write leaves a pending handoff file in this stage directory.

## Implementation correction audit

Final field-level review identified that the first conditional reference consumed FUNC EFC instead of mean FD. The verified mean FD is global input column 60 (index 12 within ANAT6+FUNC10). The same review required semantic features to be multiplied by their partial matching mass and required ROI degree support to propagate into edge-pooled concept evidence. These are corrections implementing the registered field identity, coverage and rejection constraints; Prompt text, mappings, all hyperparameters, architecture width, residual cap and scientific screening criteria were unchanged. The affected E3–E9 runs were invalidated and excluded, then recomputed once using the corrected implementation. E0, raw E1 and global-reference E2 were preserved. `results/correction_audit.json` records the excluded metrics and hashes so the correction cannot be mistaken for a performance-selected rerun.

Coverage support uses the geometric mean of the two endpoints' existing `degree/(degree+3)` shrinkage. A concept's six evidence channels are multiplied by its actual matched mass before entering the trainable adapter. Unsupported semantic features therefore vanish while unmatched numeric observations remain available in the numerical evidence fields. Direction is a weak population prior in one fixed score term, not a per-edge clinical sign label.

All adapters register 182,016 parameters. Some evidence blocks are disabled in particular arms; effective input-connected and elementwise nonzero-gradient parameter counts must therefore be reported separately. E7 preserves per-concept edge counts but not exact edge overlaps or anatomical coverage; its degree-stratified ROI permutation is metadata and the actual control uses fixed random verified-edge sets. E8 uses four train-only FC-correlation clusters with unequal sizes. These control limitations constrain claims of perfectly matched capacity or coverage.
