# 实验九结果：PDAI Prompt-Disease-Adversarial Alignment Interaction

生成时间：2026-10-12T17:37:30Z。训练配置为8组×3 seeds×10 folds；历史参考120折只读。

## 1. 研究背景

前八轮结果呈现一致边界：实验一P1(91.80%/91.62%)只比原始P0(91.69%/91.54%)略高；实验二状态Prompt未超过P1；实验三固定缩放对照较差且部分配置切断语义MLP梯度；实验四疾病相关FC文本低于P1；实验五MLP结构/衰减调整未提升；实验六标量方向门控未形成稳定收益；实验七双主题融合F1约91.69%/91.49%，没有超过P1；实验八S1疾病类别对齐为91.73%/91.51%，疾病分支概率与P1约0.958相关，增益小且有重复信息迹象。

因此本实验不再改写Prompt或调超参数，而是用固定P0/P1/P3、D0/D1、A0/A1全因子对照，检验三种机制能否产生可配对、可解释的交互。

## 2. DeepASD借鉴依据

DeepASD原文的Fig.1将流程分为模态对抗编码、逐模态患者图学习/加权融合、GNN分类；其编码器与模态判别器竞争，使表示难以由模态识别，再进入图学习。论文采用平方损失与invert-label式训练，本实验采用GRL+交叉熵，因而是受启发的轻量移植，不是复现。其Table 2在ABIDE A中，特征提取器单独约72.78% ACC/77.59% AUC，加入模态判别器后为76.74%/82.99%；完整系统为87.38%/92.76%。原文正文把82.99到77.59描述为下降6.51%，但表中数值相减为5.40个百分点，本报告以表内值为准。DeepASD的队列、划分和网络均不同，数值不能与本项目直接横向比较。[DeepASD原文](https://www.nature.com/articles/s41398-024-02972-2)。

## 3. 实验假设

P因素检验基础语义文本；D因素原样复用实验八S1疾病类别方向；A因素在GFR之后、跨模态注意力之前，对四模态V向量施加四分类GRL。主要假设是疾病监督保留类别方向时，对抗对齐可能减少模态分布差异；同时要检查是否损害ASD/TD可分性，以及这种交互是否依赖P0/P1/P3。

## 4. 实现和审计

输入为871名受试者、PHENO/ANAT/FUNC/Correlation维度48/6/10/256，raw DX_GROUP减一后0=ASD、1=TD。读取的V张量形状为[N,4,36]。判别器为LayerNorm(36)-Linear(36,32)-ReLU-Linear(32,4)，新增1388参数；GRL固定0.03，L_adv直接加入损失。D1新增36,865参数，lambda=0.1、temperature=0.2、gamma=0.2*tanh(alpha)。原始GFR/PLN Adam lr=.0038、weight_decay=.11；疾病投影和判别器weight_decay=0。原始10折、seed 0/1/2、450/200、ACC checkpoint及hard-label AUC保持不变。源代码、数据、CLIP和Prompt/Patch哈希及本地/GitHub版本见manifest.json。

初始化预检验证GRL前向恒等、特征梯度反号且幅度0.03、判别器梯度与普通CE相同、V投影梯度非零；A1与A0相同随机种子的PLN/疾病参数及初始输出完全一致。Checkpoint同时保存/恢复GFR、PLN、判别器。

## 10. 结论与后续方向

本实验不依据结果追加超参数搜索。实测结果解读见下节；配对比较为描述性结果，不将三个seed的30折误当独立样本。

## 实测结论

- 新训练组中ACC最高为E9（91.883% ± 0.195pp），Hard-AUC最高为E9（91.692% ± 0.193pp）。E9相对P3历史基线E8的ACC配对差为+0.345pp。
- 重点P1联合组E7相对原始P1 E4：ACC -0.114pp、Hard-AUC -0.088pp、SEN-ASD +0.327pp、SPE-ASD -0.503pp；相对历史疾病组E5：ACC -0.038pp、Hard-AUC +0.014pp；相对P1对抗组E6：ACC -0.038pp、Hard-AUC -0.070pp。E7没有稳定胜过这些P1参照。
- 疾病×对抗的配对交互ACC为P0 +0.382pp、P1 +0.037pp、P3 -0.268pp。P0出现正交互，P1接近零，P3为负，提示该交互依赖基础Prompt；三个seed的方向与幅度须结合上表逐seed结果看待。
- D1单独作用在P3时，E9相对E8的ACC配对差为+0.345pp；但三组D1相对各自D0的变化并不一致，不能总结为通用疾病文本增益。
- A1测试集模态判别平均ACC为24.83%（四分类机会水平25%），但R@1均值为0.0039，接近256个训练样本随机配对的基线。D1背景下E3−E1两两MMD变化+0.0343，E11−E9变化-0.0383，分布差异没有跨Prompt一致下降；E7相对E5没有历史V特征可比较。判别器接近机会水平不足以单独证明受试者级跨模态对齐。
- E7疾病分支与原分类器概率相关为0.9599，高于实验八S1历史均值约0.9577；平均gamma为+0.10372。这没有显示E7降低预测冗余，且E7相对E5的分类变化接近零。
- 零向量率各模态均为零；A1/D1部分组的类间/类内分离比降低，且疾病×对抗结果因Prompt而异。结合ACC、MMD与R@1，证据支持模型学到了可训练的判别/分布机制，但不支持稳定、普适的诊断增益或受试者配对改善。后续若继续，应先检验类别保护的选择性对齐及私有/共享表示，并在独立测试协议评估，不再对本实验调参。
