## 学习一个可移动的 16 维正交子空间

以每折规范定向的历史 U0 初始化，新增参数 W∈R^(144×16)，初始精确为零。令 T=(I−U0U0ᵀ)W，E=T/√(1+||T||²_F/4)，L=chol(I+EᵀE)，U=(U0+E)L^(−ᵀ)。Cholesky 仅为 16×16，Gram 条件数≤5，U 的正交化与反向均用 FP64。前向方向定向连续。单独保留 U0 缓冲只用于原初始化、正则与固定权重诊断。谱漂移正则为 0.05·(16−||U0ᵀU||²_F)/16。

G1 在本轮合法训练原 CAM 对两类估计 144 维均值、无偏协方差和总体协方差，充分统计量停止梯度。对每类用 90% 类协方差、10% 总体协方差及 max(1e−4, 0.01·tr(C_all)/144)·I 收缩。投影后用中间协方差 C=(C_ASD+C_TD)/2 计算
`B = dᵀC⁻¹d/8 + (logdet(C) − [logdet(C_ASD)+logdet(C_TD)]/2)/2`。
Cholesky 计算二次型及 logdet。最小化 −B/(1+B) 与谱漂移正则之和。

G2 从当前原头以本次真实 Dropout mask 计算未增强 CAM 的合法训练患者 NLL。对逐患者 NLL 的和仅求 ∂/∂z，逐行独立，关闭二阶梯度。权重 0.25+0.75σ(1−m_off)，分别在 ASD 与 TD 内归一化，两类等权。训练 H=Σw_i g_i g_iᵀ，最小化 −tr(UᵀHU)/(tr(H)+1e−12) 与相同谱漂移正则之和。测试推理不计算带标签梯度。

## 动态统计、Prompt 和残差

类别 EMA 在原始 CAM144 坐标中以 FP64 保存两类计数、均值与未中心化二阶矩。初始化使用逐折合法 E61 CAM。各轮训练和评估以当前 U 投影同一原坐标状态。总体方差用于中心化和白化，两类方差和类别协方差对比重新投影。类别方差使用历史 90/10 池化及相对、绝对下限，LLR 正号支持 ASD。初次预检测到 FP32 等价写法的舍入在类别密度差和小校准尺度处被放大，冻结版在 FP64 完成类别 log 密度差与平滑限幅，再转换为网络 dtype。独立复算保留原精度门槛。完成优化和评估选模后，将该轮评估的原 CAM144 合法行以 0.1 EMA 更新一次。Best 携带评估前 EMA，Latest 携带更新后 EMA。Fold2 历史第 377、407 行仍在原 DARG train/test，新增目标、统计、EMA 和带标签机制扣除两行，残差精确为零。

原八条 Prompt 缓存保留，文本行 4–7 对应 ASD=0，0–3 对应 TD=1。旧方向 token、相对光谱可靠性、两类 Prompt 覆盖及 Null 结构保留。冻结 P75 绝对语义差和 LLR 尺度，样本取合法训练初始化 CAM。患者和方向的混合比例限制于 [0.35,0.65]，语义与统计均保留通道。使用 tanh 有符号门控，零初始化末层。令 D 为可靠性和 Null 加权的融合 signed difference，θ=g·D，r=θ·normalize(JU)，δ=limit(r Uᵀ,z)。J 由原头确定性无 Dropout 的 ASD−TD gap 求输入导数，并停止梯度。δ 的 8% 平滑相对限幅和其梯度作用在真实 144 维特征上。轻量语义目标针对实际证据的有效方向 Σ(θ·(JU)²)/(Σ(JU)²+ε)，使用合法训练标签做类别平衡 logistic 损失。对历史同掩码 off 真类 Margin 高的训练行，增加平滑 Margin 下降与相对残差平方惩罚。

## 同一真实 Dropout 与梯度协调

每轮只调用一次原 E74.4 随机训练前向。原分类头前 Hook 接收真实 `z+δ`。原 head Dropout 的输入与输出记录同次二值掩码，用对输入的 VJP 获得其乘子。未增强参考头复用这个乘子，计算当前权重的同掩码 residual-off 梯度，保持历史图、Pair 等项。它用于估计同一点上的增量与 G2 统计。实际主优化目标只有原真实增强分类与旧图损失。各共享组用原历史优化器归属，CAM 与原头单列。令 g_B 为同掩码 off 的原总损失梯度，g_E 为增强总损失梯度。对 Δ=g_E−g_B 移除在 g_B 上的负投影，再限制 ||Δ||≤0.05||g_B||，使用 g_B+Δ 更新三个历史优化器。参考梯度为零冻结该组的本次新增增量，原本未使用参数保持无梯度。最终在原梯度 dtype 中检查投影后实际范数与点积。记录每组差异与共享权重漂移，两正式组使用完全相同规则。新增参数接收全部真实增强主分类梯度，四项辅助仅注入新增参数，合计范数按组限制为真实分类梯度的 0.25 倍。新增 AdamW 为 lr 0.0005、WD 0.01。

## 固定干预、复现与判定

residual-off 置零 δ。spectral-guidance-off 将已训练 U 替换为 U0，重新投影相同的 CAM144 EMA。semantic-evidence-off 将语义差和原 Null 影响归零，令保留的统计通道重新经相同融合及门控，权重全保持。四种推理无额外随机采样。这些干预用于即时机制，医学文本的独立增益需要另行识别。

只运行 G1、G2 各正式十折，B0 读取历史 Best。冻结真实配对未舍入 ΔACC>0、ΔBA≥0、总体净纠错>0、直接净纠错>0、ΔProb-AUC≥−0.1 pp、ΔSEN≥−0.5 pp。去 Fold2 和分别去掉 ACC、BA、净纠错最大贡献折后要求同方向。机制另要求每折谱基 rank 16 且投影矩阵位移大于 1e−4、分类梯度真实、辅助预算满足、LLR 与当前 U 一致、残差影响概率。最大 450 epoch，wait>200 停止，Latest 每十轮与终止提交。

seed=0 与固定历史十折、val=test 选模、CV 前 RFE 与 scaling、转导图全部保留。历史结果用于同协议配对，独立泛化性能另需独立验证。
