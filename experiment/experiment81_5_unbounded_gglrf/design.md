# E81.5 — Unbounded GGLRF

One formal group, ten folds: E81.5-G1-Pairwise-Unbounded-GGLRF. The only model change relative to E81.4-G2 is delta=raw_delta. Capped replay is diagnostic only. No new parameters, gates, classifier, text or modalities.

The actual E81.4 implementation is copied: global 144→32; local 16×9→32 plus position; global-conditioned queries with 8 fixed head directions; 15 unique nonself neighbors and a zero-value Null; Pairwise product and signed-difference Key/Value; global-conditioned beta; selected=16*beta*m_local; shared zero-initialized Linear(32,9) and original coordinate order. Both implementations have 16,384 parameters and use private CPU salt 814000+fold.

All new global/local input uses z_rel=detach(z)+0.1*(z-detach(z)); the identity path z is unscaled. Formal delta=raw, with no amplitude nonlinearity or cap. The residual denominator is detached. Null-only/off exactly return CAM144. A single pre-hook feeds enhanced features to the original 144→36→2 OutputLayer with Dropout(0.35). Nonzero residual changes the ordinary classification gradient and joint parameter trajectory; eta only controls the new input path.

Each task independently calls audited E74.4-G2 prepare(fold), restoring E61 epoch-10 full model, three optimizers, RNG, split and 4096 pairs. Fourth AdamW(.0005,.01) steps last. Loss is historical_out.total + .001*mean_legal_train(delta_ratio**2), with no coefficient changes. Original historical losses, seed0, 450 maximum epochs, wait>200 and strict test-ACC selection remain unchanged. Fold2 rows376/406 have zero new delta during training and are excluded from its regularizer; evaluation applies the full model uniformly.

Preflight checks actual historical initialization, all ten exact train-mode baseline forward/hidden/loss/gradients/updates/RNG, actual trained-checkpoint capped replay, nonzero-head single-variable difference, eta, neighbor/patient isolation and serialized two-step recovery. Source/config/dependency hashes freeze before formal training. RNG triples compare only common executed epochs against E74.4-G2 and E81.4-G2. Regularizer gradients are measured by autograd.grad without accumulating into parameter.grad; exactly one total backward and unchanged forward order are retained.

Independent audit recomputes six metrics from best checkpoints, checks latest/four optimizers and strict earliest ACC maxima, and compares full/off/null/global-off/Unary inference. Historical E81.4 weights are additionally evaluated in capped and unbounded modes without training or selection. Raw ratios, regularizer contributions and gradients are reported, including ratios above10/20/50/100%. Net corrections are decomposed historical DARG→current off→full, with Fold2 excluded separately.

Hard-AUC means balanced accuracy; Prob-AUC means probability ROC-AUC; ASD=0. All metrics use fold mean and population SD. Paired intervals are descriptive because training folds overlap. Historical val=test selection, pre-CV preprocessing/RFE, transductive graph and Fold2 overlap limit interpretation. Latent tokens have no anatomical validation. The original paper RES motivates global/local fusion but has no E81.4-specific 10% norm cap; original PEN is not reinstalled. No test-based tuning is permitted.
