# Experiment 38 rerun: B0-A anchored LCHER

This rerun treats the Experiment 32 `B0` implementation as the only admissible baseline. The original GFR and complete PLN construction are preserved, including unused PEN parameters and the eight original prompt buffers so construction and initialization follow the historical path. The isolated `PLN.forward` bypasses SPGS and RES after CAM and sends the flattened CAM output to the original OutputLayer. No physical PEN deletion is used as a baseline.

The first stage is an exact seed-0, continuous-stream, ten-fold replay on physical GPU 0. Before every fold's first update, `.runtime/anchors/fold-NN.pt` stores the constructed model, both Adam states, the Python/NumPy/Torch CPU/CUDA entry RNG, hashes, protocol and data provenance. Every fold is compared with the Experiment 32 B0 record for confusion counts, four historical metrics, best epoch, epochs executed, trunk SHA and entry RNG SHA. Any mismatch sets `ANCHOR_REPLAY_FAIL` and blocks all innovation arms.

Only after the anchor gate passes may E1-E9 be initialized from the matching fold anchor. New branch initialization must use an isolated RNG and append a zero-decay parameter group to the existing PLN Adam; it must not perturb the original GFR or PLN initialization. E-group folds are paired by restoring the B0 fold entry state and are not described as naturally continuous cross-fold random streams.

The frozen prompt inventory is in `prompts.json`; H01-H13 are the only candidate groups and H14-H16 are archival. Prompt text is a provided literature synthesis, not a GPT-4 API output or clinician-authenticated statement. The original raw FC coordinates are `X[:, 64 + edge_index]`; mixed GFR/CAM features are never called ROI features. The historical validation-equals-test checkpoint rule, global preprocessing/RFE, and transductive graph remain, so results are internal historical-protocol comparisons rather than unbiased clinical generalization estimates.

The run is staged under `/tmp/SPromptGL-E38-B0A-stage/experiment/experiment38_lcher_b0a_anchor_rerun` because the initial `/data` atomic-write health check returned OSSFS `EIO`. No root source, data, or prior experiment is changed. At completion, a bounded copy and byte/hash verification will be attempted; `handoff.md` will only be appended after its current prefix hash is captured and verified.
