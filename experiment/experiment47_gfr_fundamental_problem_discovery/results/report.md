# Experiment 47：GFR真实科学问题发现与机制归因

## 结论先行

本轮完成了 Stage A 静态图审计和 Stage B 固定 checkpoint 干预、条件信息探针，十折全部完成；没有启动 Stage C 重训。B0-B 与 CAM-only 均逐折精确复核。最强且达到方法级证据门槛的问题是：**原始 GFR 的患者图分支在实际训练目标下没有形成可辨认的增量决策通路**。它不是“图边不存在”，而是图消息在融合覆盖、残差路径和优化目标共同作用下几乎不改变最终 CAM 表示，因此图关系是否有益无法通过原 GFR 的分类行为被识别。这个问题具有研究价值，但本轮没有把任何解决方案写入实验。

邻居条件探针还显示：原始四图的真实邻居统计比随机邻居更有结构，但在控制自身特征后没有超过 SELF；CAM36 空间同样没有稳定的正增量。因此“邻居包含信息”与“GFR 能把信息转成独立疾病判别”被明确分开。站点聚集、过平滑和测试 cohort 依赖没有得到足够的因果证据。

## 1. 论文、代码和历史审计

原论文为 [SPromptGL MICCAI 2025](https://papers.miccai.org/miccai-2025/paper/5129_paper.pdf)，并核对了当前公开仓库 [tangaii/SPromptGL](https://github.com/tangaii/SPromptGL)。论文 Section 2.1 的 GFR 用四个模态相似图进行图传播，Eq.(1) 图损失约束学习图，Eq.(2) 用邻接矩阵进行两层消息传播；论文 Fig.2 报告的 GFR 消融数值不能直接替代公开实现审计。

本轮使用 Experiment43.1 的 PEN-free 隔离源码快照和逐折最佳 checkpoint。源码证据如下：

|位置|实际事实|性质|
|---|---|---|
|`.runtime/sources/network.py:31–42`|`GraphLearn` 只用 `p(x)` 后的余弦和固定阈值 mask；`w`、`t`、`threshold` 没有进入 forward|确定的工程事实|
|`:95–144`|四模态都传播完整 320 维；`i==1` 重新写入 `f_w*feat1+raw`，覆盖 `i==0` 的 PHENO 消息|确定的工程缺陷|
|`model.py:130–151`|simple-2 优化 `ClsLoss + mean(GraphConstructLoss)`；返回的 `ALoss` 只打印，不进入 loss|确定的训练目标事实|
|`layers.py:192–202`|每支 GCN 是两层 `GraphConv`，最终输出仍为 320 维|确定的传播事实|

历史证据：Experiment43.2 报告 GFR 输出相对原输入约 `6.9216e-05`，关闭四支消息没有类别翻转；Experiment44 的效用教师没有建立可靠未见接收者排序；Experiment44.1 在科学预检停机；Experiment45 仅说明 PID 可靠但不具判别性；Experiment46 只测固定 Top-16 均值，而且整体 LayerNorm 耦合了自身和邻居。Experiment39 的实际目录不在当前工作树，只能作为 handoff 中的未复核线索，未把它当作本轮直接证据。

## 2. 基线身份和执行范围

输入为实际 `processed_standard_data.csv` 的 871×320 数据，四模态 `[48,6,10,256]`，ASD=0、TD=1；PHENO 真实字段是 26 个年龄分箱、20 个站点 one-hot 和 2 个性别 one-hot。本轮没有虚构 FD、DVARS 或其他不存在的质量字段。候选图是原始 GFR 的 871×871 阈值图，而不是 Experiment46 的 Top-16 图。

十折 B0-B 预测与 Experiment43.1 逐折混淆、四指标完全一致；CAM-only 与 Experiment43.4 逐折完全一致：

|基线|ACC|Hard-AUC|SPE-TD|SEN-ASD|
|---|---:|---:|---:|---:|
|B0-B 原始 GFR|91.7294 ± 2.8596|91.6046 ± 2.8059|93.1360 ± 4.5354|90.0732 ± 3.5117|
|CAM-only|91.7294 ± 3.0819|91.4880 ± 3.0586|94.6346 ± 3.7878|88.3415 ± 3.3369|

十折均值使用 population SD，正式指标仍只有 ACC、硬标签 Hard-AUC、SPE-TD、SEN-ASD。GPU0 执行 folds 1–5，GPU1 执行 folds 6–10；Stage A/B 共 10 个固定 checkpoint 任务。没有重新训练 GFR，也没有改变历史 `val=test` 选模、预 CV RFE/标准化或 transductive 871 节点协议。

## 3. Stage A：原始四图和混杂审计

每折对四张真实阈值图统计节点度、权重、连通分量、同类富集、站点富集、图间支持重叠和消息范数。训练折的零假设保持每行非自环度，并另设站点匹配随机关系；测试标签只做事后检查。

|关系|训练加权同类率|度保持零均值|相对零假设 z 均值|站点匹配 z 均值|训练同站点加权率|训练内跨站点同类率|最终消息/输入范数|
|---|---:|---:|---:|---:|---:|---:|---:|
|PHENO|0.50035|0.50196|-1.46|-1.56|0.11278|0.49905|0.60315（中间消息，最终被覆盖）|
|ANAT|0.50220|0.50189|0.36|0.34|0.19896|0.50093|约4e-5|
|FUNC|0.50690|0.50321|2.91|2.78|0.33216|0.50313|约2e-5|
|CORR|0.51268|0.50231|5.52|5.75|0.11493|0.51165|约2e-5|

CORR 在 10/10 折、FUNC 在 8/10 折超过约 1.96 的站点匹配零分布阈值；ANAT、PHENO 没有稳定富集。CORR/FUNC 的跨站点同类率仍高于站点内随机基线，说明它们不能简单归结为同站点标签比例。六对图的支持 Jaccard 仅约 0.084–0.196，权重相关约 0.055–0.247；结构差异本身不能被解释为疾病互补。

这组结果不支持“原始四图完全没有疾病结构”。相反，CORR/FUNC 有小而跨折稳定的统计疾病关系；但它们尚未证明能给患者自身特征提供条件增量。因此 P1 的总体状态为 **INCONCLUSIVE**，不能把低同质性等同于图无效。

站点关系确实存在，尤其 FUNC 的同站点边比例约 0.33；但站点匹配零假设、跨站点同类率和固定模型站点干预没有显示分类损害。P2 状态为 **OBSERVED_ASSOCIATION_ONLY**，不是 `P2_SITE_CONFOUNDED_PATIENT_RELATIONS`。

## 4. Stage B：传播和条件信息

### 4.1 固定 B0-B 图干预

所有干预都不更新参数；把邻接替换为 self-loop 时，正确重新归一化。十折平均：

|干预|ACC|Hard-AUC|平均正确类 log-prob 变化|预测翻转|原正确变错|原错误变对|
|---|---:|---:|---:|---:|---:|---:|
|B0-B 原图|91.7294|91.6046|—|—|—|—|
|全部邻居消息关闭|91.6144|91.4826|-0.000005|0.115%|1|0|
|PHENO 关闭|91.7294|91.6046|0|0|0|0|
|ANAT 关闭|91.6144|91.4826|-0.000025|0.115%|1|0|
|FUNC 关闭|91.7294|91.6046|+0.000017|0|0|0|
|CORR 关闭|91.7294|91.6046|+0.000003|0|0|0|

PHENO 单独的 GCN 消息范数很大，但它在 `i==1` 被覆盖；最后 GFR 输出相对 raw 输入的十折平均比例仅约 `7e-05`。因此没有证据表明两层传播造成了持续过平滑或分类损害。P4 状态为 **HYPOTHESIS_NOT_SUPPORTED**；更准确的现象是传播没有充分进入决策。

站点匹配随机图、全局度保持随机图、仅同站点图和仅跨站点图的固定干预均保持原四项分类结果（最多一折一例边界翻转）。这排除了“仅凭同站点比例就能解释分类”的说法。

上表中的均值和 population SD 保留四位小数；CSV 是逐折唯一数值来源。RAW320 的 TRUE 比 SELF 平均低 5.3932 个百分点，且 0/10 折胜 SELF；但 TRUE 比 RANDOM 高 5.6322 个百分点、比 SITE_RANDOM 高 4.8263 个百分点、比 PERMUTED 高 2.1800 个百分点。CAM36 的 TRUE 比 SELF 低 0.6883 个百分点，只有 2/10 折胜 SELF；没有稳定超过负控制。由此得到：真实图关系不是任意随机上下文，但在控制患者自身特征后没有稳定的正增量。P3 状态为 **SUPPORTED_BUT_NOT_FULLY_ATTRIBUTED**，不是“其他患者绝无信息”。

### 4.3 表征变化和测试 cohort 检查

训练/测试类别分离比例（类间平方距离/类内平方距离）显示：CAM hidden 测试约 6.94，而 GFR output 与 raw input 都约 0.061；这与 GFR 输出近似恒等一致，不支持“传播把表示过度拉平”作为主要原因。固定模型中保持目标患者自身特征不变，只置换其余测试患者的 30 个目标保持样本，固定图的平均绝对 log-prob 变化约 `8.35e-06`、0 次翻转；重算 transductive 图也为 0。包含目标自身的全测试置换会造成约 34% 翻转，但它改变了目标输入，不能用于 P6 结论。P6 状态为 **HYPOTHESIS_NOT_SUPPORTED**。

## 5. 优化和损失归因

在每个 B0-B 最佳 checkpoint 上，使用完全相同输入分别对分类损失、四图 `GraphConstructLoss` 和未优化的 `ALoss` 求梯度：

|量|十折均值|
|---|---:|
|GFR 参数的分类梯度范数|0.031945|
|GFR 参数的图正则梯度范数|0.245390|
|GFR 参数的 ALoss 梯度范数（仅诊断）|0.617858|
|CAM 参数的分类梯度范数|6.719414|
|GFR 分类/图正则梯度余弦|−0.000028|
|GFR 分类/ALoss 梯度余弦|+0.000185|

按关系看，PHENO 的分类梯度为 0（覆盖路径）；ANAT/FUNC/CORR 的 GraphLearn 分类梯度约 `7.5e-05/3.4e-05/3e-06`，而相应图正则梯度约 `0.0775/0.0523/0.1943`。`GraphLearn.w/t/threshold` 在 forward 中没有可用梯度；只有 `p` 参与相似度。固定消息关闭几乎不改变分类，历史 E43.2 也得到 0/871 翻转。

这不是单独证明“去掉图正则一定能恢复性能”：本轮没有为了追逐结果而启动重训，且 CORR/FUNC 的条件关系本身也没有给出超过 SELF 的稳定增量。它证明的是一个更基础的功能限制：**在原始残差和融合覆盖下，分类目标没有把患者图分支变成可辨认的判别通路；图正则仍在推动图参数。** P5 由源码、梯度、十折固定干预和历史复核四类证据共同支持，状态为 **VERIFIED_MAJOR_GFR_PROBLEM**。`PHENO` 覆盖、未使用参数和 ALoss 不反传是直接工程缺陷；“图分支不可识别”是超出单行修复的 GFR 方法级问题。具体哪一种重训目标能够解除它，本轮不回答。

跨模态支持重叠和消息余弦较低，但没有对应的分类影响：P7 状态为 **OBSERVED_ASSOCIATION_ONLY**，不能包装成互补机制。

## 6. 根因区分矩阵

|科学现象|本轮证据|结论|
|---|---|---|
|图消息很弱|最终消息/输入约 `7e-05`、PHENO 覆盖、分类干预无翻转|图分支未进入决策；原因包含已证实覆盖和残差/目标捷径|
|图消息很弱是邻居无信息|CORR/FUNC 同类率超过匹配零假设，TRUE 高于随机|不能归因于完全无邻居结构|
|加强消息造成过平滑|表示几乎等于 raw，关闭消息不损害分类|未支持|
|同站点聚集造成疾病损害|站点匹配/跨站点固定干预无影响，跨站点仍有同类富集|仅观察到站点关联|
|TRUE 不如 SELF 是输入尺度伪影|自身/邻居分离标准化、CAM36 复核、合成正控制|输入耦合解释被明显削弱，但不是所有表示/模型的证明|
|GFR 不如 CAM 是图无价值|真实图结构有 CORR/FUNC 信号，但 GFR 不使用它|更符合图分支不可识别，而非图绝对无价值|
|GraphConstructLoss 阻碍分类|图正则梯度约为分类梯度 7.7 倍，方向近正交；无单因素重训|梯度冲突被支持，单独因果量仍未隔离|
|测试 cohort 依赖|目标保持置换 30 次无翻转、重算图无变化|未支持 P6|
|四模态结构差异代表互补|支持重叠低但条件增量和分类关闭无稳定收益|仅结构差异，未证实互补|

## 7. 问题状态和科研判断

|问题|状态|证据范围|
|---|---|---|
|P1 图主要不是疾病结构|**INCONCLUSIVE**|PHENO/ANAT 近零，CORR/FUNC 有稳定小富集；不能总括四图|
|P2 站点混杂造成损害|**OBSERVED_ASSOCIATION_ONLY**|站点率存在，但匹配零假设和干预没有分类损害|
|P3 条件邻居增量|**SUPPORTED_BUT_NOT_FULLY_ATTRIBUTED**|TRUE 非随机但不超过 SELF；只适用于本图、特征和探针|
|P4 传播过平滑破坏判别|**HYPOTHESIS_NOT_SUPPORTED**|消息近恒等，关闭消息仅 1/8710 测试样本翻转量级|
|P5 图分支不可识别/优化捷径|**VERIFIED_MAJOR_GFR_PROBLEM**|源码覆盖、梯度失衡、固定干预、十折历史一致性共同支持|
|P6 测试 cohort 依赖|**HYPOTHESIS_NOT_SUPPORTED**|目标保持置换没有实质响应|
|P7 跨模态冲突导致损害|**OBSERVED_ASSOCIATION_ONLY**|图支持差异存在，但无分类影响证据|

本轮最强的一个问题足以支持后续方法学研究：原 GFR 的图分支在当前残差融合和损失组合下不可识别，导致“图是否有益”无法由分类结果回答。它比单纯修复 PHENO 覆盖更有研究价值，因为即使关系图存在 CORR/FUNC 的统计疾病信号，原始分类路径仍不使用它。P3 是第二个较弱、尚未完全归因的问题：真实邻居携带部分结构，但没有稳定超出自身信息的条件增量。

这不等于已经有 MICCAI 2027 第一创新点。当前证据支持 **继续做问题导向的 GFR 研究设计**，不支持宣称某个解决方案有效；下一轮必须在预注册的单因素训练对照中验证“解除图分支不可识别”是否真正能把条件邻居信息转为独立分类收益。若无法做到，应该永久停止固定患者相似图路线。Stage C 本轮没有启动，也没有提出 Experiment48。

## 8. 局限和交付

本轮仍沿用 `val=test`、预 CV RFE/标准化、transductive 871 节点、单 seed；十折共享训练患者，不能当作十个独立临床样本。固定模型干预可能产生分布外输入；条件探针是诊断证据，不是新的正式分类模型。`ALL_TEST_ROWS_PERMUTED` 明确不用于 P6 因果结论。没有下载外部模型、没有使用 CLIP/GPT/PID/反事实教师、没有修改根目录源码或数据。

结果文件：`graph_statistics.csv`、`conditional_probe.csv`、`interventions.csv`、`gradient_diagnostics.csv`、本报告和 `manifest.json`。运行源快照、输入哈希、checkpoint 哈希记录于 manifest。目标 `/data` 目录的同步须在交付时再次校验；若 OSSFS 仍失败，handoff 会保留 `/tmp` 路径和未同步状态，不声称完成。
