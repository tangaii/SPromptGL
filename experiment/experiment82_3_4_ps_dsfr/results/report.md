## 研究问题与历史核对

E82.3.3 在固定 Best 下已观察到 2.63%–3.32% 的相对残差和平均真类 Margin 上升，两组关闭残差均零硬翻转，十折 ACC 均低于 DARG。本轮检验同一患者两类医学 Query 的竞争性谱证据，能否在原 CAM144 上形成有分类价值的方向级修正。

SPromptGL 的 GFR 用模态关系图和 GCN 表示患者。CAM 在每个患者内融合模态。原 PEN 用冻结 CLIP、SPGS 局部 token 加权和 RES 局部到全局融合。DARG 路径延续 PLNNoPEN，CAM 由 FeedForward 后展平得到 871×144，送入原 LayerNorm→Linear→GELU→Dropout→Linear 分类头。 [原论文](https://papers.miccai.org/miccai-2025/paper/5129_paper.pdf) · [原作者代码](https://github.com/wanxixi11/SPromptGL/tree/ba3b9446fa451fde6864d6555bdf324de0c4b64a)

## 方法和冻结协议

E82.3.3 的标量 SignedGate、beta 混合与一阶 DecisionGain 已移除。PS-DSFR 将残差加在 CAM144 上，保留原始分类头和主分类损失的端到端梯度。

- $h=zU$ 承载有符号残差，$\hat h=(z-\mu)U/\sqrt{\lambda+\epsilon}$ 供历史 Gaussian 和谱 token 使用。固定 $U$ 的列、符号和 dtype 沿用历史身份。
- $A_c=1-\prod_{j\in c}(1-a_{j,1:16})$，$N_c$ 为各类 Null 均值，$C_c=(1-N_c)A_c/(\sum A_c+\epsilon)$。$S=C_{ASD}-C_{TD}$。用历史有界 ASD/TD Gaussian LLR $\ell$ 和可靠性 $R=(1+\tanh(16w_{sp}))/2$ 构造 $E_c=C_cR\sigma(\ell\tanh(16S))$，$D=E_{ASD}-E_{TD}$。
- $g=\tanh(\mathrm{MLP}_{178\to16\to16}([\mathrm{LN}(z),D,R,N_{ASD},N_{TD}]))$，末层权重和偏置精确置零。$\delta=\mathrm{smooth\_limit}((g\odot D\odot h)U^T,z)$，使用原 8% 径向 tanh 限幅，并对极小范数保证真实相对限幅。原分类头使用 $z+\delta$。
- $L_{DARG}=L_{cls}+L_{graph}+0.05L_{pair}+0.01L_{adv}+0.01L_{preserve}$。$L_{sem}$ 是两类证据总量归一化后的类均衡 NLL；$L_{safe}$ 按 $\sigma(\mathrm{stopgrad}(m_y)-2)$ 连续加权合法训练行的相对残差平方。$L=L_{DARG}+s(0.01L_{sem}+0.001L_{safe})$，$s$ 使用冻结的逐组梯度范数预算 0.5。这两个辅助项只向新增参数注入梯度。

G1 用固定医学 Query，G2 用几何匹配的历史匿名 Query。历史 6081 个参数使用 822000+fold 的原初始化。新门控使用 823500+fold 的隔离初始化。固定文本向量和谱基；学习 Query 条件化的 direction、evidence、LayerNorm、key、Null 与谱可靠性网络。新增 AdamW 的 lr=0.0005、weight decay=0.01；三个历史优化器完整恢复。

seed=0，历史十折，val=test，严格 ACC 提高才更新 Best，平局保留较早 epoch。从 epoch 10 恢复，最多 450 epoch，wait>200 停止，每十轮及终止保存 Latest，先使用旧 EMA 评估与冻结 Best，再更新 EMA（α=0.1）并保存 Latest。沿用 CV 前 RFE/scaling 和转导图。Fold2 的行 377 和 407 保留历史训练和测试身份，排除新增 EMA/监督和带标签机制诊断，新增残差严格为零。

首选 OSSFS 路径创建失败（errno 5），所有正式产物写入同一回退目录。
